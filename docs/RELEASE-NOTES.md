## Client
- Native AmigaOS 3.2 Rocket.Chat client with multiple servers, channel and direct-message trees, and per-server connection events.
- Separate Preferences application with session-only Use, persistent Save, and one shared configuration file.
- Unread room navigation, mention badges and new-message markers.
- Multiline messages, code blocks, clipboard support, clickable links and authenticated attachment downloads with progress and cancellation.
- Lazy image previews, avatar and emoji controls, Workbench iconification and reconnect recovery without automatic message replay.

## Integration
- Native plugin SDK with Timestamp and Quick Reply examples.
- ARexx control, state snapshots and sequenced notifications for dock integration.

## Distribution
- Workbench install/update/uninstall workflow preserving settings and unrelated plugins.
- Verified runtime LHA, plugin SDK ZIP and corresponding-source ZIP with checksums, build provenance and reviewable publication manifests.
